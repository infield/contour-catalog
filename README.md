# Contour catalog

Reference libraries for the Contour bit library app: bit profiles (one pack
per manufacturer), machines, spindles and ATCs. Served by GitHub Pages;
the app reads `index.json` and downloads packs on request.

Packs are built with `catalog-builder` in the Contour repo and published here.
Vendor data is redistributed with each vendor's permission (see `attribution`
and `license` in `index.json`).
